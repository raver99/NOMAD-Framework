# Knowledge Base

What this project holds to be true. One document per topic, indexed below.

Documents live under `knowledge/`, named `kebab-case.md`. Group them into subdirectories only once a
group has more than a few; a directory holding one file is noise. Each document opens with a purpose
statement, uses numbered sections so it can be cited precisely from elsewhere, and ends with a
References table of `| # | Source | Tier | Retrieved |`. Tiers are **primary** (the thing itself),
**live state** (the thing right now) and **secondary** (someone describing it).

Every external claim carries a numbered reference. A claim that is the project's own judgement says
so in the sentence rather than citing nothing.

Values that move on someone else's schedule — versions, deadlines, prices, limits under active
revision — are not recorded here. Record which gate exists and link the page that states the current
value. A copied date goes wrong invisibly, because it reads like every durable line around it.

A finding too small to fill a document waits in its research record. It does not become a stub, and
it does not collect in a notes document.
